# Pastel Calculator

A simple, clean, and beginner-friendly calculator built with **HTML, CSS, and vanilla JavaScript only**.

Features a soft pastel lavender and blush pink theme with a simple, readable layout that is easy to understand and maintain.

---

## Features

- **Basic Arithmetic**: Addition (`+`), Subtraction (`−`), Multiplication (`×`), and Division (`÷`).
- **Helpful Operations**:
  - Decimal point (`.`) with duplicate prevention.
  - Percentage (`%`).
  - Positive/Negative sign toggle (`+/–`).
  - Delete single character (`DEL`).
  - Clear all (`AC`).
- **Dual Display**:
  - Top line shows the previous number and chosen operator.
  - Main line shows the active number and final calculated result.
- **Keyboard Support**:
  - Numbers `0`–`9`
  - Decimal point (`.` or `,`)
  - Operators `+`, `-`, `*` (or `x`), `/`
  - Calculate with `Enter` or `=`
  - Delete with `Backspace`
  - Clear with `Escape`
